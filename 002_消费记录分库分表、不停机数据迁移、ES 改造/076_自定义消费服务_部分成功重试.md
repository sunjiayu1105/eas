# 076_自定义消费服务_部分成功重试

## 1 问题

一条消息有多行，部分写入成功后超时，何时可以确认消费？

## 2 高级 Java 面试核心考点

整条重投时区分成功、重复、过期、冲突和结果未知。答到必要状态保存、异常上抛和失败恢复。 本题承接[从 MQ 写入 ES 时，为什么项目选择自定义消费服务？](<./072_自定义消费服务.md>)。

## 3 面试口述版本

口述内容字符数：110

监听器逐行调用 ES，只有全部行处理完成且必要状态保存成功，才正常返回。某一行超时就保留结果未知状态并抛出异常，让 MQ 重投整条消息。已成功的行仍用原主键、索引和版本处理，核实旧事件或相同内容的重复。相同版本却字段不同，要留下差异，不能当作成功。
