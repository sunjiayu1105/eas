# 054_在线历史迁移_任务区间

## 1 问题

首次迁移怎样划分任务区间，才能覆盖稀疏主键并处理空表？

## 2 高级 Java 面试核心考点

按旧主键最小值和最大值划定不重叠的区间。按主键跨度估算任务数，稀疏区间可能读不到行，生成区间时检查任务上限和边界溢出。 本题承接[旧系统持续服务时，历史迁移批次从什么条件下启动，到什么条件下可以交给一致性校验？](<./053_在线历史迁移.md>)。

## 3 面试口述版本

口述内容字符数：100

取旧主键的最小值和最大值，把整个跨度分成互不重叠且连续覆盖的区间，每个任务在自己的区间内按主键分页。主键有空洞时允许读到空区间。生成清单前检查区间边界、任务数上限和溢出。空表没有上下界，零任务应进入哪个终态仍待确认。
