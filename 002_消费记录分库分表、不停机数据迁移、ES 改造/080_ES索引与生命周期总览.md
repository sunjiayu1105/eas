# 080_ES索引与生命周期总览

## 1 问题

消费记录的 ES 索引怎样按月组织，并覆盖创建、更新、冷热迁移和到期清理？

## 2 高级 Java 面试核心考点

项目可从不可变创建时间直接推导历史物理索引，跨月更新仍指向同一文档，也可按月份生成清理清单。采用滚动索引时需要另外说明历史更新如何定位原索引。

## 3 面试口述版本

口述内容字符数：105

用不可变的创建月份命名物理索引，后台列表通过读别名跨月查询。自动任务提前一个月建索引，更新和重放按原始月份写回同一文档。历史回放先使用临时策略，校验通过后再切正式冷热策略。到期由年度任务按月份清单删除，并在写入侧检查保留窗口。
