# 060_在线历史迁移_部分派发失败

## 1 问题

启动事务已经提交，线程池只接收了一部分迁移任务就拒绝后续提交，批次该怎么收尾？

## 2 高级 Java 面试核心考点

区分事务提交、线程池接收和数据库操作完成三个时点。说明已接收、未接收和接收结果未知三类任务的处理，以及允许恢复前需要取得的证据。 本题承接[旧系统持续服务时，历史迁移批次从什么条件下启动，到什么条件下可以交给一致性校验？](<./053_在线历史迁移.md>)。

## 3 面试口述版本

口述内容字符数：100

停止继续派发，保留已接收任务的句柄，通知它们收尾并核实在途数据库操作。未接收的任务保留原状态，接收结果不明的要核对任务入口、日志和数据库结果。最后按启动时保存的完整任务清单判定批次状态，避免把已经生效的工作整批重派。
