# 058_在线历史迁移_暂停收尾

## 1 问题

收到暂停请求后，要等到什么条件满足，才能把批次记为“已暂停”？

## 2 高级 Java 面试核心考点

停止信号、Future 与 JDBC 收尾、全任务清单和终态竞争。 本题承接[旧系统持续服务时，历史迁移批次从什么条件下启动，到什么条件下可以交给一致性校验？](<./053_在线历史迁移.md>)。

## 3 面试口述版本

口述内容字符数：113

收到暂停请求后先停止继续派发和读取下一页，再等待已接收任务结束，核实在途 JDBC 写入和提交的实际结果。取消 Future 或等待超时都不足以证明数据库已停止。对照完整任务清单，确认没有仍在执行或结果不明的操作后，才能将暂停中的批次更新为已暂停。
