# 048_业务双写

## 1 问题

业务双写如何保证旧表提交后，新表最终收到同一次变更？

## 2 高级 Java 面试核心考点

本地事务保存业务变更和同步消息，宕机后扫描恢复，确认目标写入后标记完成。

## 3 面试口述版本

口述内容字符数：97

写旧表时，把这次变更的业务数据、版本和待同步消息放在同一数据库事务里。提交成功后即使应用宕机，后台也能扫描到消息，用原版本写新表。只有确认目标已写入或已由更新版本覆盖后，才标记完成。积压和持续失败还要告警并对账。
