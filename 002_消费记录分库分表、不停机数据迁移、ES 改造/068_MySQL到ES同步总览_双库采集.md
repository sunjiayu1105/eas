# 068_MySQL到ES同步总览_双库采集

## 1 问题

怎样保证两个新库在历史导入期间的变更也能被采集？

## 2 高级 Java 面试核心考点

在双写产生首笔新表变更前分别记录两个新库的 GTID 基线，双写上线时开启新表到 ES 的同步，核对行日志、账号权限和保留窗口。重启时根据可靠进度和剩余日志判断能否续接。 本题承接[新库的变更怎样同步到 ES，后台列表何时能查到这笔记录？](<./067_MySQL到ES同步总览.md>)。

## 3 面试口述版本

口述内容字符数：90

双写产生第一笔新表变更前，分别保存两个新库的 GTID 基线，检查行日志、权限以及保留窗口。双写上线就开始同步，历史导入产生的写入也要被采集。恢复时每个实例使用自己可靠的进度，先确认所需日志仍能读取。
