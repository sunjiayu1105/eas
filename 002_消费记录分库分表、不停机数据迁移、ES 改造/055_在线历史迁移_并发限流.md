# 055_在线历史迁移_并发限流

## 1 问题

怎样限制历史迁移对在线业务的影响？出现什么现象时应该降低并发？

## 2 高级 Java 面试核心考点

连接与内存预算、有界队列、页大小、批间等待和压测。 本题承接[旧系统持续服务时，历史迁移批次从什么条件下启动，到什么条件下可以交给一致性校验？](<./053_在线历史迁移.md>)。

## 3 面试口述版本

口述内容字符数：97

先给在线请求预留数据库连接、CPU 和内存，再确定后台迁移并发。用有界队列限制积压，控制每页行数和批间等待。如果在线延迟、连接等待或数据库负载持续上升，先降低并发或减小批次，再观察是否恢复。具体阈值和并发度需要压测。
