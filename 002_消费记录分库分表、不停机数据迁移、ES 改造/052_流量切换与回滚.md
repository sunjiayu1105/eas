# 052_流量切换与回滚

## 1 问题

全量灰度读已稳定，怎样证明可以交接主写？切写后回退需要什么条件？

## 2 高级 Java 面试核心考点

纳入灰度的读流量全部切换并稳定至少半天后，才能进入写交接。暂停新写，等在途事务结束，追平最后一笔旧表提交并完成最终校验，隔离旧写入口后交接。

## 3 面试口述版本

口述内容字符数：105

灰度读全量稳定至少半天后才进入交接。先暂停新写，等待在途事务结束，确认最后一笔旧表提交已同步，再做最终校验。通过后隔离旧写入口，启用新表主写。切写后新产生的数据可能只在新表，回退前要先回补旧表并核对一致，直接改路由会丢掉这段变更。
