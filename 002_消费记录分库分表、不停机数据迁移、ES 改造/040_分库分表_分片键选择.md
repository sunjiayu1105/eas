# 040_分库分表_分片键选择

## 1 问题

消费记录为什么选择商户号作为分片键？这个选择有什么代价？

## 2 高级 Java 面试核心考点

商户号的可获得性、稳定性、按商户定位、热点及跨商户查询代价。 本题承接[消费记录的分库分表方案是怎样设计的？](<./039_分库分表.md>)。

## 3 面试口述版本

口述内容字符数：81

交易写入时就能取得商户号，而且同一笔交易的商户号稳定。按商户查流水时，读写能定位到同一个分片。代价是大商户可能造成热点，跨商户查询也要访问多个分片，因此后台跨商户列表另走 ES。
