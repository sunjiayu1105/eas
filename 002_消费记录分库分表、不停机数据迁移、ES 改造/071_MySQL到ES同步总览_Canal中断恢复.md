# 071_MySQL到ES同步总览_Canal中断恢复

## 1 问题

Canal 中断后，怎样判断两个源实例各自还能否从原进度追上？

## 2 高级 Java 面试核心考点

逐实例核对对应 destination 最近可靠进度、所需日志是否仍可读取，以及积压和恢复期间的追赶能力。保留期配置值本身不能证明所需日志仍在；缺少必要日志时，不可跳到最新位置宣布恢复。 本题承接[新库的变更怎样同步到 ES，后台列表何时能查到这笔记录？](<./067_MySQL到ES同步总览.md>)。

## 3 面试口述版本

口述内容字符数：109

逐实例查对应 destination 的最近可靠进度，并实际检查源库还保存着从该位置开始的日志。再比较积压量、源库新增速度和采集速度，判断恢复期间能否追平。如果所需日志已经清掉，就要先确认缺口并制定补数方案，跳到最新位置会漏掉中间的变更。
