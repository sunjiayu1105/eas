# 041_分库分表_库表路由

## 1 问题

给定商户号，如何算出消费记录所在的实例和物理表？

## 2 高级 Java 面试核心考点

商户号哈希映射到逻辑分片，再按每实例 16 张表计算实例编号和表编号。迁移、查询和写入共用同一路由。 本题承接[消费记录的分库分表方案是怎样设计的？](<./039_分库分表.md>)。

## 3 面试口述版本

口述内容字符数：97

先按统一规则规范化商户号，哈希后对 32 取非负余数，得到 0 到 31 的分片号。用分片号整除 16 得到实例编号，对 16 取余得到实例内表号。例如分片 23 对应实例 1、表号 7，再按配置找到物理表。查询、迁移和写入必须共用这套路由。
