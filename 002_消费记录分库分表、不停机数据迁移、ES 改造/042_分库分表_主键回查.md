# 042_分库分表_主键回查

## 1 问题

只拿到业务主键时，怎样回查分片记录？

## 2 高级 Java 面试核心考点

区分全局唯一和能够定位分片。说明主键设计、可用路由信息及缺失时的回查代价。 本题承接[消费记录的分库分表方案是怎样设计的？](<./039_分库分表.md>)。

## 3 面试口述版本

口述内容字符数：99

设计把分片号编码在消费主键 consumeId 的末尾两位。回查时先取出这两位，检查是否落在 00 到 31，再按分片号定位实例和表，最后用完整主键查记录。只有全局唯一性、没有路由信息的主键，仍需要额外的路由映射或跨片查找。
