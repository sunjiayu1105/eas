# 072_自定义消费服务

## 1 问题

从 MQ 写入 ES 时，为什么项目选择自定义消费服务？

## 2 高级 Java 面试核心考点

围绕消息格式、按原始创建月份路由、传递外部版本、区分版本冲突及整条消息重投，说明项目需要掌控哪些处理步骤。比较 Adapter 时按具体版本及已核实能力作答。

## 3 面试口述版本

口述内容字符数：114

自定义消费服务让项目能按每一行的原始创建月份、主键和业务版本组装 ES 请求，再按写入结果决定整条消息能否确认。它还负责区分旧版本、重复和同版本字段冲突。选择的代价是团队承担解析、重试、告警和维护，比较 Canal Adapter 时要核对具体版本的能力。
