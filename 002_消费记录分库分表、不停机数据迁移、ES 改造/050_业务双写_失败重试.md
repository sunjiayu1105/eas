# 050_业务双写_失败重试

## 1 问题

新表可能已写成功，但同步任务没有收到响应。再次处理这条消息时，怎样判断它能否标记为完成？

## 2 高级 Java 面试核心考点

用原消息重试、根据目标版本判定结果、完成标记与超限告警。 本题承接[业务双写如何保证旧表提交后，新表最终收到同一次变更？](<./048_业务双写.md>)。

## 3 面试口述版本

口述内容字符数：96

超时只能说明调用方没收到结果。后台用原消息和原版本重试，读目标记录核对版本和内容。目标是同版本且字段相符，或已确认更高版本生效，才可结束旧消息。目标缺失或落后就继续写，同版本不同内容要保留差异，持续失败要告警。
