# 084_ES索引与生命周期总览_到期删除

## 1 问题

怎样按自然年删除数据，并防止过期消息重建已删索引？

## 2 高级 Java 面试核心考点

按业务时区保留本年度和之前四个自然年。说明撤销新增业务记录、到期清理由独立任务执行，对查询、回放和补偿采用相同下界，按月份清单执行整索引删除。 本题承接[消费记录的 ES 索引怎样按月组织，并覆盖创建、更新、冷热迁移和到期清理？](<./080_ES索引与生命周期总览.md>)。

## 3 面试口述版本

口述内容字符数：97

按业务时区保留本年度和之前四个自然年。年度任务列出窗口以外的月份，核对后整索引删除。查询、回放和补偿共用保留下界，迟到的过期消息先按窗口拦住，避免重新创建已删索引。MySQL 的物理删除和 ES 的年度任务各自执行。
