# 046_改造计划_双写入口覆盖

## 1 问题

启动在线历史迁移前，怎样判断业务双写已经覆盖了所有写入口？

## 2 高级 Java 面试核心考点

覆盖服务、定时任务和脚本的增删改入口，核对版本改造和同步消息，解释漏改入口的后果。 本题承接[在线迁移从启用双写到新表接管主写，按什么顺序上线？](<./044_改造计划.md>)。

## 3 面试口述版本

口述内容字符数：101

逐一列出会修改旧表的服务、定时任务和脚本，检查每个增删改入口是否同时记录同步消息，以及创建和更新是否遵守业务版本规则。再用代表性请求核对已提交变更能进入新表。只要还有入口能绕过消息记录，就可能漏掉历史扫描之后的更新。
