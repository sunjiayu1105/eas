# 066_状态与任务初始化事务_锁等待超时后的事务结局

## 1 问题

初始化任务时一条 SQL 锁等待超时，能否直接重试整个批次？

## 2 高级 Java 面试核心考点

InnoDB 默认在锁等待超时时回滚当前语句，先前成功的语句仍可能留在事务中。应用要使整个初始化事务回滚并核实结果，再决定能否重试。 本题承接[首次启动时，为什么修改批次状态和初始化任务必须在同一个事务中执行？](<./065_状态与任务初始化事务.md>)。

## 3 面试口述版本

口述内容字符数：101

按 InnoDB 默认行为，一条 SQL 锁等待超时可能只回滚该语句。事务中前面成功的写入仍可能保留，所以先让整个初始化事务回滚，核对批次状态和任务清单后再决定是否重试。如果是提交响应丢失，数据库可能已经提交，直接重跑会误判。
