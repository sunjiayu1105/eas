# 051_新旧表一致性校验

## 1 问题

旧表仍在写入时，怎样找到缺失、多余和字段不一致的记录，并安全修复？

## 2 高级 Java 面试核心考点

分片、分块双向扫描，用稳定流水号关联。行数和指纹用于缩小差异范围，逐字段定位，修复时核实来源并用版本条件防止覆盖新值。

## 3 面试口述版本

口述内容字符数：102

按分片、分块从两端扫描，用每条记录唯一的 serialNo 匹配同一笔流水。行数和指纹帮助缩小范围，再逐字段核对缺失、多余和内容差异。修复前重读当前主写表，以版本条件保护并发更新。在线校验后仍可能有新写入，切写前还要做最终校验。
