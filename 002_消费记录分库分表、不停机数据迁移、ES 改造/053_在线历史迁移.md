# 053_在线历史迁移

## 1 问题

旧系统持续服务时，历史迁移批次从什么条件下启动，到什么条件下可以交给一致性校验？

## 2 高级 Java 面试核心考点

确认双写覆盖全部入口后，保存扫描范围并初始化任务清单。事务提交后派发任务，按页写入并记录进度。暂停后沿用原任务恢复，全部任务完成后交给新旧表一致性校验。

## 3 面试口述版本

口述内容字符数：99

所有入口的双写生效后才能启动历史迁移。首次启动在同一事务里更新批次状态、保存扫描范围并初始化任务，提交后才派发。各任务分页搬运，整页写入确认后保存游标。暂停时先收尾，恢复时沿用原任务。所有任务成功后再交给新旧表对账。
