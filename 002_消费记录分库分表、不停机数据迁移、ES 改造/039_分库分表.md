# 039_分库分表

## 1 问题

消费记录的分库分表方案是怎样设计的？

## 2 高级 Java 面试核心考点

设计采用 2 个独立的 MySQL 实例，每个实例放 16 张消费记录表，共 32 个物理分片。分表控制单表数据和索引规模，分实例分散读写和维护负载。

## 3 面试口述版本

口述内容字符数：116

设计是两个独立 MySQL 实例，每个实例 16 张消费记录表。用商户号做分片键，统一规范化并哈希后对 32 取非负余数。分片号决定实例和表，业务读写和迁移共用同一套路由。这样能限制单表规模并分散实例负载。大商户仍可能集中在一个分片，所以还要验证容量和峰值负载。
