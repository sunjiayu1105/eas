# 059_在线历史迁移_故障恢复

## 1 问题

实例宕机后批次仍显示“运行中”，怎样判断能否安全恢复？

## 2 高级 Java 面试核心考点

旧执行隔离、未决事务、任务状态修复与人工重新启动。 本题承接[旧系统持续服务时，历史迁移批次从什么条件下启动，到什么条件下可以交给一致性校验？](<./053_在线历史迁移.md>)。

## 3 面试口述版本

口述内容字符数：96

先查旧实例是否仍能执行，以及是否还有未决数据库事务。隔离旧执行后，对照持久化任务清单、游标和实际写入核实哪些任务完成、哪些可重放。修复异常状态后再从原任务恢复。只看到实例离线或批次长时间运行，都不足以直接重启。
