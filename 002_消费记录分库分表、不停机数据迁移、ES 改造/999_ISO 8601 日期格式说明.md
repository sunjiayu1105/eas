# ISO 8601 日期格式说明

ISO 8601 是国际通用的日期时间表示标准。

例如：

```text
2026-09-06T14:00:00+08:00
```

其中：

- `2026-09-06`：日期；
- `T`：日期与时间的分隔符；
- `14:00:00`：时间；
- `+08:00`：比 UTC 快 8 小时，即中国标准时间。

其他常见形式：

```text
2026-09-06T06:00:00Z
2026-09-06T14:00:00.123+08:00
2026-09-06
```

这些日期字符串属于 ISO 8601 格式，Elasticsearch 的 `strict_date_optional_time` 可以解析。
