# 082_ES索引与生命周期总览_索引创建恢复

## 1 问题

下个月的 ES 索引由谁创建？如果跨月时它还没建好，写入怎样恢复？

## 2 高级 Java 面试核心考点

日常由自动任务提前一个月创建目标月份索引。创建失败时告警，自动任务无法完成创建时由运维手工补建。 本题承接[消费记录的 ES 索引怎样按月组织，并覆盖创建、更新、冷热迁移和到期清理？](<./080_ES索引与生命周期总览.md>)。

## 3 面试口述版本

口述内容字符数：105

自动任务提前一个月创建目标索引，失败就告警，自动任务无法完成时由运维手工补建。历史回放提前准备所需月份。发现保留期内的目标索引缺失，保留重试机会，建好后核对映射、读别名和生命周期设置，再向原月份重投。任务和告警的实际效果仍待验证。
