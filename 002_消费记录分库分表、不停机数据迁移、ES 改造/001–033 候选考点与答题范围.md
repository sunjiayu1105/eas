# 001–033 候选考点与答题范围

本清单的 33 道题、答题范围和对应文档已由用户确认。题号用于对照答案。以下内容按照当前项目 `AGENTS.md` 项目级规则中规定的技术栈版本为准。

## 改造与分片

### 1. 后台列表为什么适合从 MySQL 迁到 ES？

按商户分片可以定位交易写入。跨商户筛选、排序和分页需要访问多个分片，查询副本可隔离这类负载。答到哪些查询能容忍同步延迟。

基于项目拟题。[原文 001](<./001_改造原因.md>)

### 2. 历史数据搬运、切读、切写分别在什么时候进行？

先启用双写，再在线搬运并灰度切读。最终短暂停写，追平校验后一次性交接主写。

基于项目拟题。[原文 002](<./002_改造计划.md>)

### 3. 怎样从商户号算出目标库表，并判断分片是否解决了容量问题？

从容量目标推导分片数，用统一哈希算出逻辑分片，再映射到实例和表。结合热点商户、容量分布和无路由键查询说明限制。

基于项目拟题。[原文 003](<./003_分库分表.md>)

### 4. 只拿到业务主键时，怎样回查分片记录？

区分全局唯一和能够定位分片。说明主键设计、可用路由信息及缺失时的回查代价。

基于项目拟题。[原文 003](<./003_分库分表.md>)

## ES 同步、校验与保留期

### 21. 从 MySQL 提交到 ES 可查询，中间哪几个成功信号容易混淆？

按源库提交、采集、MQ 发布、消费确认和 ES 查询可见性逐层解释。指出每个信号能证明哪一步，哪些延迟要另行观测。

基于项目拟题。[原文 023](<./023_ES改造.md>)

### 22. 怎样保证两个新库在历史导入期间的变更也能被采集？

每个源实例在导入前记录 GTID 基线，核对行日志、账号权限和保留窗口。重启时根据可靠进度和剩余日志判断能否续接。

基于项目拟题。[原文 024](<./024_ES改造_MySQL.md>)

### 23. Canal 怎样把一次事务里的多行变化转换成 MQ 消息？

从行事件讲到 FlatMessage 的表名、操作、行数据和分区。用多行更新说明数据库事务、Canal 批次、MQ 消息的范围。

基于项目拟题。[原文 025](<./025_ES改造_Canal Server.md>)

### 24. 消息已经发给 RocketMQ，Canal 还没保存进度就宕机，会发生什么？

核对发布结果、批次确认和位点持久化的顺序，推导重放条件。说明单机恢复依赖的位点和源库日志。

基于项目拟题。[原文 025](<./025_ES改造_Canal Server.md>)

### 25. 并发消费时，同一记录的后一次更新先到 ES 怎么办？

区分消息路由、监听方法内逐条调用与不同回调的完成顺序。解释选择并发时为什么需要目标端原子版本比较。

### 26. 消费端如何把 INSERT、UPDATE、DELETE 转成正确的 ES 操作？

检查事件字段，按源记录的创建时间和业务主键定位文档，区分完整文档写入、删除、字段不足的处理。

### 27. ES 物理删除之后，迟到的更新会让数据重新出现吗？

解释删除版本保留窗口、已发出的旧请求和删除状态之间的关系。仅扫描仍存在的 MySQL 记录无法发现全部多余 ES 文档。

### 28. 一条消息有多行，部分写入成功后超时，何时可以确认消费？

整条重投时区分成功、重复、过期、冲突和结果未知。答到必要状态保存、异常上抛和失败恢复。

### 29. 跨月更新或删除怎样直接找到原来的 ES 文档？

用不可变创建时间和统一时区定位月份，业务主键作为 _id。说明读别名、索引模板和自动创建的条件，以及物理索引定错时版本比较为何失效。

### 30. 增量校验怎样兼顾时间回看、分页和失败续跑？

每张物理表保存由更新时间和唯一键组成的游标，区分每轮回看和页内翻页。失败页保留恢复位置，说明源表扫描的删除盲区。

### 31. MySQL 和 ES 版本相同、字段却不同时，如何安全修复？
