# 079_新表与ES增量校验_同版本差异修复

## 1 问题

MySQL 和 ES 同版本却字段不同，为什么反复重试原请求修不好？

## 2 高级 Java 面试核心考点

严格外部版本写入会拒绝相等版本。重新核对源行和目标状态，记录差异；修复须防止并发新版本被覆盖。 本题承接[已有实时同步，为什么还要扫描新表核对 ES？这种校验有哪些盲区？](<./077_新表与ES增量校验.md>)。

## 3 面试口述版本

口述内容字符数：102

严格外部版本写入要求请求版本大于目标版本。同版本字段不同时，原请求即使再发也会被拒绝。先重读新表和 ES，确认差异还存在，记录差异并保留失败页游标。修复必须防止覆盖刚到的新版本，项目中保留源版本的并发安全修复方式仍待验证。
