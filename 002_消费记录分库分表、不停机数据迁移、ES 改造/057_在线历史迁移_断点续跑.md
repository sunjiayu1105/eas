# 057_在线历史迁移_断点续跑

## 1 问题

并行迁移时，一页数据写成功但进度保存失败，重启后从哪里继续？

## 2 高级 Java 面试核心考点

任务级持久化游标、整页确认、结果未知和重放边界。 本题承接[旧系统持续服务时，历史迁移批次从什么条件下启动，到什么条件下可以交给一致性校验？](<./053_在线历史迁移.md>)。

## 3 面试口述版本

口述内容字符数：103

每个并行任务各自保存最后一个已完整写入页面的末尾主键。整页写入确认后才推进游标。如果写成功而游标没保存，重启就从上一持久化位置重新读这页，靠唯一键和版本条件安全重放。某个任务跑得快，不能用它的最大主键覆盖其他任务的进度。
