# 044_改造计划

## 1 问题

在线迁移从启用双写到新表接管主写，按什么顺序上线？

## 2 高级 Java 面试核心考点

先覆盖全部写入口，再在线搬运和校验。提前发布新路径，灰度时继续双写，只在主写交接时暂停业务写入。

## 3 面试口述版本

口述内容字符数：108

先改造所有写入口，使旧表业务变更和同步消息在同一事务提交。双写上线时就启动两个新库到 ES 的同步，再在线搬运历史数据并对账。发布新读写代码后，先灰度放开允许延迟的查询，期间继续双写。最终交接主写才停新写、等在途事务结束、追平并做最终校验。
