## 2 问题

已有数据库状态条件更新，为什么还在批次启动入口使用分布式锁？

## 3 高级 Java 面试核心考点

解释减少数据库争用的收益、引入 Redis 的代价，以及为什么仍要靠数据库条件更新和事务提交判断能否启动。

**入选理由** 上一级问题讲启动锁的使用流程。本题进一步考查权衡数据库争用与 Redis 依赖，说明入口互斥和数据库资格判断各解决什么问题。

## 4 面试口述版本

口述内容字符数：107

两个应用实例有各自的 JVM，本地锁拦不住另一个实例。它们用同一批次 ID 竞争同一个 Redis 锁，失败者在开启数据库事务前就返回，因此减少同一行上的锁等待。代价是启动依赖 Redis。批次状态能否改变仍由数据库条件更新和事务提交决定。
