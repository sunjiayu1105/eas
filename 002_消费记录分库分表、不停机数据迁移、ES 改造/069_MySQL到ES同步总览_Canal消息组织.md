# 069_MySQL到ES同步总览_Canal消息组织

## 1 问题

Canal 怎样把一次事务里的多行变化转换成 MQ 消息？

## 2 高级 Java 面试核心考点

从行事件讲到 FlatMessage 的表名、操作、行数据和分区。用多行更新说明数据库事务、Canal 批次、MQ 消息的范围。 本题承接[新库的变更怎样同步到 ES，后台列表何时能查到这笔记录？](<./067_MySQL到ES同步总览.md>)。

## 3 面试口述版本

口述内容字符数：114

Canal 将行变更解析为事件。按项目的扁平 JSON 格式，同一条消息描述来源表、操作类型及一组行数据。生产端还会按路由与分区配置组织发送。例如一次事务修改多行，消费端要逐条读取消息里的行，不能把数据库事务、Canal 拉取批次和 MQ 消息当作一一对应。
