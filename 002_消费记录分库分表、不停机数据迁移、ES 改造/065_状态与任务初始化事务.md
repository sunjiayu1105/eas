# 065_状态与任务初始化事务

## 1 问题

首次启动时，为什么修改批次状态和初始化任务必须在同一个事务中执行？

## 2 高级 Java 面试核心考点

分别提交的故障后果、完整回滚、语句失败和启动提交结果未知。

## 3 面试口述版本

口述内容字符数：117

首次启动依据未启动状态创建任务。若先提交任务而状态更新失败，下次请求还会进入初始化。若先提交运行中而初始化失败，批次又会拒绝正常启动。把状态、扫描范围和任务清单放进同一个事务，全部提交后才派发。遇到语句异常要让整个事务回滚，提交结果不明时先查持久化状态。
