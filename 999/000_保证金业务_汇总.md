# 一、业务概述
## 1. 保证金定义
保证金是用于核算存入银行等金融机构、具有保证金性质的存款。  
本业务中，银行与第三方商户合作，个人客户在银行开立账户并存入资金完成业务交易，作为履约保证金参与第三方商户提供的合约优惠活动，由第三方为客户提供合约优惠权益。

## 2. 产品类型
目前主要包括两类：

1. 活期圈存保证金
2. 定期无息保证金

## 3. 业务收益
1. 通过与第三方商户合作拓宽业务渠道，引流零售客群。
2. 带动分行零售基础客群和个人存款规模增长。
3. 定期无息保证金业务可为分行带来利息收入。

# 二、活期圈存、定期无息保证金业务
## 2.1 业务流程
### 2.1.1 冻结流程
综合保证金业务商户接入模式分两种：

1. 全 API 对接模式
2. H5 + API 对接模式

文档重点描述 **H5 + API 对接模式**。

### 冻结主流程
1. 客户在商户前端办理保证金业务。
2. 商户上送业务参数，请求获取跳转 H5 链接。
3. 开放平台处理获取链接请求。
4. 根据接入方式生成 H5 链接并返回前端。
5. 客户通过 H5 链接进入银行 H5 页面。
6. H5 页面回显业务办理信息。
7. H5 调用 **FM0091 账户开户冻结预校验接口**。
8. 系统根据客户账户情况、冻结金额、证件号等信息推荐开户类别。
9. H5 根据查询结果判断是否需要新开户：需要开户则进入 H5 开户流程；不需要开户则进入保证金交易页。
10. 客户提交保证金冻结请求。
11. 投资理财系统完成账号密码校验。
12. E 账通调用 **FM4921 综合保证金存入接口**。
13. 根据产品属性进入活期圈存或定期无息流程。
14. 完成冻结交易。
15. 返回交易结果至前端。
16. 同步或异步通知商户交易结果。

### H5 跳转链接获取方式
1. **openbankcode 方式**：商户调用开放平台接口并上送业务参数，开放平台保存参数至本地，生成 token 压参至 URL，返回 H5 跳转 URL。
2. **短链接方式**：商户调用开放平台接口并上送业务参数，开放平台请求中台基础中心完成压参并生成 URL，返回 H5 跳转 URL。
3. 当前常用方式：**短链接方式**。

### FM0091 账户开户冻结预校验逻辑
1. 查询客户是否存在一类户：
    - 存在：返回一类户，允许交易账户级别为 1。
    - 不存在：继续后续判断。
2. 判断冻结金额是否大于等于 2000 元：
    - 大于等于 2000 元：
        * 查询是否存在自营三类户。
        * 存在三类户：返回升级标志，允许交易账户级别为 2。
        * 不存在三类户：继续查询是否存在自营二类户。
        * 存在二类户：返回二类户。
        * 不存在二类户：返回新开立二类户。
    - 小于 2000 元：
        * 查询是否存在自营三类户。
        * 存在三类户：判断账户余额与冻结金额合计是否超过 2000 元。
        * 未超过：返回三类户。
        * 超过：按二类户逻辑处理。
        * 不存在三类户：查询是否存在自营二类户。
        * 二、三类户均不存在：返回新开立三类户。
3. 出参账户集合返回客户已有的一类户、自营渠道二类户、三类户账户列表。

## 2.1.2 FM4921 综合保证金存入接口逻辑
### 总体处理逻辑
1. 根据入参产品属性判断产品类型：圈存或无息。
2. 圈存分支：
    - 调用 **FM7151**。
    - 判断套餐使用标识。
    - 使用套餐：查询圈存套餐信息。
    - 不使用套餐：根据入参冻结金额、冻结时长处理。
    - 完成活期圈存交易。
3. 无息分支：
    - 查询无息套餐信息。
    - 调用 **FM4901**。
    - 完成无息定期交易。
4. 更新本地交易结果。

### 支持范围
| 类型 | 支持账户 |
| --- | --- |
| 活期圈存保证金 | 一类户、二类户、三类户 |
| 定期无息保证金 | 一类户、二类户 |


### 关键规则
1. 套餐标识为“否”时，可直接根据冻结金额、冻结时长完成余额圈存，不校验套餐信息。
2. 产品属性为圈存时，调用 **FM7151**。
3. 产品属性为无息时，调用 **FM4901**。
4. 套餐标识为“是”时，根据套餐编码和产品属性查询本地套餐配置。
5. 支持卡代收完成冻结交易。

## 2.1.4 解冻、违约扣流程
### 概念
**对公户**：以公司名义在银行开立的账户。

### 解冻 / 违约扣主流程
1. 商户前端发起解冻或违约扣请求。
2. 开放平台转发请求。
3. E 账通处理请求。
4. 根据业务类型判断交易类型：解冻或扣取违约金。

### 解冻分支
1. E 账通发起解冻请求。
2. 核心或统一支付处理解冻。
3. 解冻资金停留在二类户，或代付至绑定卡。
4. 返回交易结果。

### 扣取违约金分支
1. E 账通发起扣取违约金请求。
2. 核心或统一支付处理违约扣。
3. 违约金划转至商户对公户。
4. 返回交易结果。

### FM4922 综合保证金解冻接口逻辑
1. 根据入参圈存编号查询本地订单信息。
2. 判断原订单产品属性：圈存或无息。
3. 无息分支：调用 **FM6903**，完成无息保证金解冻。
4. 圈存分支：判断解冻类型，包括全部解冻、部分解冻、违约解冻。
5. 全部解冻：调用 **FM7152**，完成全部解冻交易。
6. 违约解冻：调用 **FM7153**，完成违约扣款并解冻。

### 规则说明
1. 支持无息保证金解冻。
2. 支持活期圈存保证金解冻、解冻扣交易。
3. 活期圈存支持全部解冻、部分解冻、解冻并提现。
4. 活期圈存违约扣支持：扣取违约金并解冻、扣取违约金并冻结。
5. 违约金实时划扣至商户对公户。
6. **FM7153** 增加渠道扣款摘要码：**XTG 违约扣款**。
7. 支持 6 个月无交易灰名单状态账户完成解冻扣交易。
8. 部分解冻扣完成后，剩余资金保持冻结状态。
9. 解冻结果支持接口推送通知商户。
10. 权益保证金扣取违约金后，系统发送提醒短信至客户。

## 3.1.1 华为 0 元购保证金存入
### 参与方
1. 华为商城
2. 华为钱包
3. 开放平台网关
4. 核心
5. E 账通

### 主流程
1. 客户在华为商城前端选择购机方案。
2. 华为商城调起华为零钱钱包购买购机支付订单。
3. 华为零钱处理购机支付订单。
4. 判断客户是否已开立广发二类户：
    - 未开立：引导客户开立广发银行二类户。
    - 已开立：发起保证金购买请求。
5. 华为发起保证金购买请求。
6. E 账通处理保证金购买请求。
7. E 账通根据订单信息查询本地购机套餐配置。
8. 校验信息是否一致并符合购机规则：不符合则拒绝交易。
9. E 账通调用核心接口发起保证金购买。
10. 核心完成保证金存入至二类户定期账户。
11. 返回交易结果。
12. 判断是否权益类订单：是则记录华为权益待下单明细。
13. 交易成功后发送冻结成功短信。
14. 结果返回前端。

### FM7120 保证金购买接口处理逻辑
1. 根据入参套餐编码校验本地套餐配置规则。
2. 校验内容包括：套餐编号、冻结金额、冻结时长、剩余库存、限购标识。
3. 存在限购标识时，调用营销中心接口查询是否允许购买。
4. 校验通过后，调用核心 **121430 华为保证金存入接口**。
5. 送核心信息包括：商品价格、成本价格、利率、借支行所等。
6. 核心据此计算我行垫付款和营业外收入。
7. 若内容未配置借支行所号，默认使用华为渠道值 **102087**。
8. 产品类型属于权益类且套餐配置为续存时，送续存标识至核心。
9. 存入成功后发送冻结成功短信。
10. 权益类产品记录权益下单待处理明细。
11. 返回交易结果至前端。

## 3.1.3 退货及提前支取
### 参与方
1. 华为商城 / 华为零钱
2. 开放平台 / E 账通
3. 核心

### 退货说明
1. 退货交易如 7 天无理由退货，目前仅支持全部退货。
2. 不支持部分退货交易。

### 提前支取说明
客户未等到保证金到期，需要提前取回保证金时，系统从冻结保证金中扣取商户价格或违约金额，剩余资金返还客户账户。

### 主流程
1. 客户在华为商城前端发起退货或违约支取请求。
2. 华为发起支取请求。
3. E 账通处理支取请求。
4. 校验原保证金订单信息。
5. 根据支取类型处理：全部退货或违约支取。

### 全部退货处理逻辑
1. 记录华为购机退货待处理明细。
2. 自动任务异步完成扎差清算。
3. 清算完成后发起全部退货请求。
4. 全额退货资金链路：定期冻结余额解冻至客户账户。
5. 全额退货为异步交易。
6. 通过华为 **9006 保证金支取退货结果通知接口** 通知退货结果。

### 违约支取处理逻辑
1. 违约金额由前端上送。
2. 查询内容配置的禁止提前支取天数。
3. 根据原订单购买日期和当前交易日期计算已存入天数。
4. 判断是否满足提前支取规则：
    - 已存入天数大于禁止支取天数：允许交易。
    - 不满足：拒绝交易。
5. 调用核心 **121440 华为保证金支取接口**。
6. 扣减违约金额至分行账户。
7. 剩余本金退回二类户。
8. 违约支取为实时交易，交易结果实时返回华为前端。

## 3.1.4 华为购机保证金扎差清算
### 清算范围
日终统计 T-1 日及历史的华为保证金存入、退货交易，将扎差资金清算至华为对公户。

### 统计维度
按订单套餐 ID 查询产品类型，并区分不同产品类型进行统计扎差。

### 实物购机取数逻辑
1. 实物购机保证金存入交易：统计 T-1 日实物购机保证金存入成功交易，取订单中的存入成本价，生成存入汇总值。
2. 实物购机保证金全额退货交易：统计 T-1 日实物购机保证金全额退货申请，取原保证金存入订单的成本价，生成退货汇总值。
3. 实物购机历史剩余扎差金额：统计历史扎差未清算的退货金额汇总值。

### 音乐类、视频类取数逻辑
1. 音乐类、视频类下单交易：统计 T-1 日音乐类、视频类下单交易，关联原保证金存入订单，统计原订单权益成本价汇总值。
2. 音乐类、视频类保证金全额退货交易：统计 T-1 日实物购机、音乐类、视频类保证金下单成功但发起全额退货申请，取订单退货成本价汇总值。
3. 音乐类、视频类历史剩余扎差金额：统计历史扎差未清算的退货金额汇总值。

### 扎差计算公式
```latex
存入汇总值 - 退货汇总值 - 存量退货金额汇总值 = 扎差金额
```

### 扎差金额处理规则
1. 等于 0：无需清算，退货申请状态变更为审批通过，由退货自动任务处理全额退货。
2. 小于 0：无需清算，记录历史未清算退货金额，退货申请保持待审核，不处理全额退货。
3. 大于 0：查询保证金清算借支行所配置，按渠道号、产品类型区分行所和商户对公户，调用核心 **351100** 接口完成垫资清算。

### 核算规则
1. 冻结：二类户活期余额 → 定期冻结余额。
2. 全部退货：定期冻结余额 → 二类户活期余额。
3. 提前支取：违约金 → 分行营业外收入；剩余定期冻结余额 → 二类户活期余额。
4. 扎差清算：核心垫资户 → 商户对公户。
5. 补回垫资款：定期冻结结息 → 核心垫资户。

# 四、核心业务链路汇总
## 1. 综合保证金冻结链路
商户前端 → 开放平台 → H5 页面 → 投资理财 → E账通 FM4921 → 核心 / 圈存接口 → 返回交易结果 → 通知商户

## 2. 综合保证金解冻 / 违约扣链路
商户前端 → 开放平台 → E账通 FM4922 → 核心 / 统一支付 → 解冻或扣违约金 → 返回交易结果 → 通知商户

## 3. 权益发放链路
H5 套餐购买 → E账通 FM4921 → 增值平台 DVS007 查询权益 → 完成圈存 → 增值平台 DVS008 发券 → 返回交易结果

## 4. 华为 0 元购存入链路
华为商城 → 华为钱包 → 开放平台 → E账通 FM7120 → 核心 121430 → 定期保证金存入 → 返回交易结果

## 5. 华为权益下单链路
核心续存成功 → 在线发布 Kafka → E账通记录待下单明细 → 自动任务调用华为权益下单接口 → 完成权益下单

## 6. 华为退货 / 提前支取链路
华为商城 / 华为钱包 → 开放平台 / E账通 → 判断支取类型 → 全部退货异步处理 / 违约支取实时处理 → 核心完成资金处理 → 返回或通知交易结果

# 六、整体业务特点
1. 业务覆盖冻结、权益发放、解冻、违约扣、退货、提前支取、清算、对账等完整生命周期。
2. 综合保证金支持 **H5 + API** 和 **全 API** 两类商户接入方式。
3. 活期圈存保证金更偏向余额冻结、解冻及违约扣。
4. 定期无息保证金更偏向定期存入、到期续存、退货和提前支取。
5. 权益类保证金需要联动增值平台或华为权益下单接口。
6. 华为 0 元购场景涉及二类户、定期保证金、权益下单、扎差清算和垫资核算。
7. 部分流程为实时交易，部分流程为异步交易：
    - 违约支取：实时。
    - 全额退货：异步。
    - 权益下单：自动任务异步。
    - 扎差清算：日终批量处理。
