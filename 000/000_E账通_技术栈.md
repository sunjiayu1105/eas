# MySQL 
MySQL 8.0.33

我项目里使用的是 MySQL 8.0.x，具体可以选择 MySQL 8.0.33。因为 MySQL 8.0.18 引入了 Hash Join，8.0.20之后很多原来 BNL 的场景改由 Hash Join 处理，所以一般不建议使用太早的 8.0 版本。同时，Spring Boot 2.7.18 默认管理的 MySQL 驱动是 mysql-connector-j 8.0.33，所以使用 MySQL 8.0.33 或 8.0.x 是比较稳妥的选择。   如果是新生产项目，也可以考虑 MySQL 8.4 LTS，但对于 Java 8 + Spring Boot 2.7.18 的项目来说，MySQL 8.0.33 是比较常见、稳定、兼容性好的选择。
