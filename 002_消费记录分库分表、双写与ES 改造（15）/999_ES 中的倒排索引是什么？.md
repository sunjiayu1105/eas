# 4.5 ES 中的倒排索引是什么？

以下内容按照当前项目 `AGENTS.md` 项目级规则中规定的技术栈版本为准。

**按词项找到文档**

倒排索引是 Elasticsearch 为字段值建立的一种索引结构，核心是记录“每个词项对应哪些文档”。对于 `text` 字段，ES 通常先通过分析器分词，再建立倒排索引；对于 `keyword` 字段，通常将整个字段值作为一个词项建立索引。

**示例：词项与文档的对应关系**

例如：

```text
Java -> [文档 1，文档 2]
ES   -> [文档 2，文档 3]
```

**查询边界：分析器和字段类型要匹配**

查询某个词项时，ES 可以通过倒排索引快速定位相关文档，减少逐条扫描。示例假定词项已经确定；实际 `text` 字段会按分析器处理大小写等内容，查询输入也要与该规则匹配。索引中还可以记录词频、词项位置等信息，用于相关性计算和短语查询。倒排索引由 Elasticsearch 底层使用的 Lucene 维护。
