# ES 7.17.15 常见字段类型

以下内容按照当前项目 `AGENTS.md` 项目级规则中规定的技术栈版本为准。

| 分类 | 常见类型 | 说明 |
|---|---|---|
| 文本类型 | `text`、`keyword` | `text` 默认启用索引，写入时经过分析器处理，通常会分词并将词项写入倒排索引；使用 `match` 等全文查询时，查询内容通常也会经过分析器处理。`keyword` 默认不分词，将整个字段值作为一个词项；配置 `normalizer` 后可以进行规范化处理，但不会拆分成多个词项 |
| 数值类型 | `integer`、`long`、`float`、`double` | `integer` 是 32 位有符号整数；`long` 是 64 位有符号整数；`float` 是 32 位单精度浮点数；`double` 是 64 位双精度浮点数 |
| 日期类型 | `date` | 表示日期和时间，可用于时间范围查询、排序和聚合 |
| 布尔类型 | `boolean` | 表示 `true` 或 `false` |

补充说明：`match` 查询会分析查询内容，而 `term` 查询通常不会分析查询值。因此，`term` 查询一般不直接用于查询经过分词的 `text` 字段。

**核验说明**：已依据 Elasticsearch 7.17 官方字段类型、数值类型及 `v7.17.15` 对应文档，核对类型支持情况、位宽和文本分析行为。

位宽说明：`integer` 的“32 位”指二进制位宽，包含符号位。因此，ES 7.17.15 中 `integer` 的取值范围是 `-2^31` 到 `2^31 - 1`，即 `-2,147,483,648` 到 `2,147,483,647`，并不是最多 32 位十进制数字。
