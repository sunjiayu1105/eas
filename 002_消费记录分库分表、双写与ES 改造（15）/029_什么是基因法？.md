# 4.7 什么是基因法？

以下内容按照当前项目 `AGENTS.md` 项目级规则中规定的技术栈版本为准。

**做法：把路由信息编码进 ID**

基因法把分片编号等路由信息写入业务 ID，使查询端能从 ID 解析目标分片，减少广播到多个分片的查询。

**项目用法：固定 2 位后缀**

本项目在雪花 ID 后拼接固定 2 位分片编号，`consumeId` 按字符串保存。例如后缀 `07` 指向分片 7，再由统一映射确定库和表。商户路由、生成后缀和查询解析必须一致。

**边界：后缀不自动完成路由**

数据库访问层需要实际识别后缀；错误值、越界值和路由映射变化也要处理。基因法本身不保证全局唯一，唯一性还依赖基础 ID 生成器。
