## 文档维护与已确认规则

- 当前同步主链路为 MySQL → Canal Server（RocketMQ 模式）→ RocketMQ → 自定义 RocketMQ 消费与 ES 写入服务 → Elasticsearch；Adapter 1.1.7 保留版本边界，但不作为主写入组件。
- db0、db1 分别维护 GTID 起点和本地消费进度，由一个单机 Server 进程承载，不使用 ZooKeeper 主备。故障后人工核对并重启，按 destination 验收原生 RocketMQ 发布恢复和 MQ 到 ES 的恢复，不共用一个确认位置。
- 本表记录待实现或待验证事项。旧 Adapter 的 retries、双别名映射和进程安排仅属历史方案，不能继续写成当前 008 的已确认规则。
