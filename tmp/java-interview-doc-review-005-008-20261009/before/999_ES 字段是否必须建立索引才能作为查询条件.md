# ES 字段是否必须建立索引才能作为查询条件

## 一句话总结

以下内容按照当前项目 `AGENTS.md` 项目级规则中规定的技术栈版本为准：**Elasticsearch 服务端 7.17.15**；动态映射自动生成的字段通常可查询，明确设置 `index: false` 的字段不能进行普通值查询，`doc_values` 不能替代索引来支持普通值查询，主要用于排序、聚合、脚本及部分 `exists` 判断。

注释 1

## 核心结论

在 ES 7.17.15 中，需要区分“没有手动配置字段”和“明确配置 `index: false`”：

- 没有手动配置字段时，如果启用了动态映射，ES 会自动创建 mapping，字段通常默认 `index: true`，因此可以查询。
- 明确配置 `"index": false` 后，该字段不能用于普通的 `term`、`terms`、`match`、`range` 等字段值查询。
- `doc_values` 主要用于排序、聚合和脚本访问，不能替代倒排索引来支持普通字段值查询。
- `exists` 只用于判断字段是否存在，不等于可以按字段具体值查询。

## 1. 没有显式配置字段

```json
PUT orders
{
  "mappings": {
    "dynamic": true
  }
}
```

`dynamic` 默认值就是 `true`。写入文档：

```json
PUT orders/_doc/1
{
  "orderId": 1001,
  "status": "paid",
  "remark": "已支付订单"
}
```

查看 mapping：

```http
GET orders/_mapping
```

结果大致如下：

```json
{
  "orders": {
    "mappings": {
      "properties": {
        "orderId": {
          "type": "long"
        },
        "status": {
          "type": "text",
          "fields": {
            "keyword": {
              "type": "keyword"
            }
          }
        },
        "remark": {
          "type": "text",
          "fields": {
            "keyword": {
              "type": "keyword"
            }
          }
        }
      }
    }
  }
}
```

因此，虽然没有手动创建字段 mapping，但动态映射已经自动创建了可索引字段。

查询数值字段：

```json
GET orders/_search
{
  "query": {
    "term": {
      "orderId": 1001
    }
  }
}
```

全文查询字符串字段：

```json
GET orders/_search
{
  "query": {
    "match": {
      "status": "paid"
    }
  }
}
```

精确查询字符串字段：

```json
GET orders/_search
{
  "query": {
    "term": {
      "status.keyword": "paid"
    }
  }
}
```

## 2. 明确配置 `index: false`

```json
PUT products
{
  "mappings": {
    "properties": {
      "productCode": {
        "type": "keyword",
        "index": false
      }
    }
  }
}
```

写入文档：

```json
PUT products/_doc/1
{
  "productCode": "P1001"
}
```

执行查询：

```json
GET products/_search
{
  "query": {
    "term": {
      "productCode": "P1001"
    }
  }
}
```

在 ES 7.17.15 中，不能按 `productCode` 的具体值进行普通查询，因为该字段没有建立倒排索引。

对于 `index: false` 且保留 `doc_values` 的 `keyword`、数值等字段，可以使用 `exists` 判断字段是否存在，但不能按字段具体值进行普通查询。

| 场景 | 是否能按字段值进行普通查询 |
|---|---|
| 动态映射自动生成 `index: true` | 可以 |
| 明确配置 `"index": false` | 不可以 |
| 仅有 `doc_values` | 不能替代倒排索引进行普通值查询 |
| `index: false` 且保留 `doc_values` | 可以执行 `exists`，但不能按具体值查询 |

## 核验说明

已依据 ES 7.17.15 官方动态映射、`index`、`doc_values` 文档，并核对该版本 `MappedFieldType`、`TermBasedFieldType` 和 `KeywordFieldMapper` 源码：

- 普通字段值查询会校验字段是否已建立索引；
- `exists` 在有 `doc_values` 时可以使用字段值数据结构判断字段是否存在；
- 动态模板、索引模板、日期检测和数字检测可能改变最终 mapping。

实际 mapping 仍应通过以下请求确认：

```http
GET index_name/_mapping
```
