# 4.11 技术栈版本与使用规则

以下内容按照当前项目 `AGENTS.md` 项目级规则中规定的技术栈版本为准。

以下为项目统一技术栈版本。本次迁移、同步和校验方案不新增 RocketMQ 消息传输链路；已有业务 RocketMQ 消费者仍属于停写和恢复的控制范围。本文不另行指定 ShardingSphere-JDBC 版本；Canal Server 和 Adapter 按项目规则固定为 1.1.7。

- **Java**：8
- **Spring Boot**：2.7.18
- **rocketmq-spring-boot-starter**：2.3.0
- **org.apache.rocketmq:rocketmq-client**：5.2.0
- **Elasticsearch 服务端**：7.17.15
- **MySQL**：8.0.33
- **Canal Server**：Alibaba Canal Server 1.1.7（ZooKeeper 主备高可用部署）
- **Canal Adapter**：Alibaba Canal Adapter 1.1.7（ES 7 Adapter）

**兼容性判断边界**：Canal 1.1.7 与项目 Java 8、MySQL 8.0.33、Elasticsearch 7.17.15 可作为版本候选，但具体依赖版本、发行包加载、认证、REST/Transport 连接和端到端同步仍需在目标环境验证。

**项目版本与候选版本分开**

正文、配置和代码示例均以上述版本为边界。Canal Server/Adapter 1.1.7 是当前项目版本边界，源码核对链接采用 `canal-1.1.7` 标签；实际安装包、ShardingSphere-JDBC、JDBC 驱动及其他未指定依赖仍须结合构建配置和联调环境核对。
