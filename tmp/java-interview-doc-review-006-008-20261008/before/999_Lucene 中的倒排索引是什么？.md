# Lucene 中的倒排索引是什么？

倒排索引的核心思想，是从词项反向找到包含它的文档。

建立索引时，Lucene 会使用 `Analyzer` 对需要分析的文本字段进行处理，得到一个个词项，再为每个“字段和词项”的组合建立倒排列表。例如：

```text
content:java   -&gt; 文档 1、文档 2
content:lucene -&gt; 文档 1
content:mysql  -&gt; 文档 2
```

倒排列表至少会记录文档编号，根据索引配置，还可以记录词频、词项位置等信息。

查询时，搜索文本通常也要经过相匹配的分析处理。比如 `Java` 被转换成 `java` 后，Lucene 可以通过词项字典直接找到对应的倒排列表，不需要扫描全部文档，因此全文检索效率很高。

需要注意的是，如果直接使用不经过分析的 `TermQuery`，查询词项必须与索引中的词项完全一致，否则可能匹配不到结果。
